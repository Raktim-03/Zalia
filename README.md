# Birthday Surprise 💗

A romantic, animated birthday website built with React, Vite, Tailwind CSS v4, Motion, and Lucide React.

## Run locally

1. Install Node.js (LTS) if it isn't installed.
2. Extract this project folder.
3. Open a terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints, usually `http://localhost:5173`.

## First milestone

- Animated opening screen
- Working "Open your surprise" reveal
- Floating petals and ambient glow
- Responsive layout
- Scroll-reveal note section
- Reduced-motion accessibility support

## Next steps

## Deploy

Run `npm run build` and deploy the generated `dist` folder to Vercel or Netlify.
